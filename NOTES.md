# St.Riders Coffee — заметки к разработке

Премиальный лендинг для концепт-кофейни St.Riders Coffee (Таганский район, Москва).
Стек: чистый HTML5 + CSS3 (design-токены в `:root`) + vanilla JS, без сборки, без фреймворков.

Файлы: `index.html`, `styles.css`, `script.js`, `NOTES.md` в
`C:/Users/gra4i/Downloads/client-sites/st-riders-coffee/`.

## Сделано

- Полная структура из ТЗ: hero, концепция, меню (7 категорий без цен), галерея
  (6 CSS/SVG-график без стоковых фото), отзывы/доверие (4.9, 16 отзывов 2ГИС),
  бронирование → WhatsApp, оплата (информационно, без полей карты), контакты, footer.
- Отдельный блок программы лояльности «Карта Райдера» (−15%) и баннер найма бариста
  (з/п до 80 000 ₽) — использованы как есть из вводных данных.
- Своя палитра «гараж на закате»: глубокий петрол-асфальт (`--color-bg`) + гоночный
  оранжевый (`--color-throttle`) + нитро-голубой (`--color-nitro`) — сознательно избегал
  клише «почти чёрный + один кислотный неон» и «кремовый + serif».
- Типографика: Big Shoulders Display (заголовки, кондовый гоночный кегль) + Manrope
  (текст) + JetBrains Mono (лейблы/приборные подписи) — три Google Fonts, не пересекаются
  с типовыми лендинг-шаблонами.
- Сигнатурный визуальный мотив — «tread-strip»: повторяющийся диагональный паттерн
  протектора/дорожной разметки, используется как разделитель между секциями и в шапке/футере
  (не буквальная шина, абстрактный графический ритм).
- Брутальные «наклейка»-панели: срезанные углы (`clip-path`) и жёсткая офсетная тень
  (`box-shadow: 7px 7px 0 …` без блюра) вместо скруглений/glassmorphism.
- Логотип — текстовый wordmark «St.Riders•Coffee» с inline SVG-акцентом (мото-штрихи),
  без картинок.
- Форма бронирования: JS собирает поля (имя, телефон, дата, время, гости, комментарий)
  в текст и открывает `https://wa.me/79686361542?text=...` в новой вкладке; под кнопкой —
  подпись «Заявка откроется в WhatsApp» точно по ТЗ.
- Доступность: skip-link, `:focus-visible` с видимым аутлайном, `aria-hidden` на всех
  декоративных SVG, `alt`/`aria-label` у смыслового графического блока (карта-схема),
  `prefers-reduced-motion` отключает анимации/transition/smooth-scroll, семантические теги
  (header/main/section/footer/nav), адаптив проверен вплоть до 360px (отдельные брейкпоинты
  980 / 560 / 380px), мобильное меню на JS-тоггле с `aria-expanded`.
- `<title>`, meta description, Open Graph, favicon как inline SVG data URI, JSON-LD
  (`CafeOrCoffeeShop`) с реальными адресом/телефоном/часами/рейтингом для SEO.
- Контраст текста проверен вручную по формуле WCAG (относительная яркость): основной
  текст на фоне ~10:1, приглушённый текст ~9–10:1, оранжевый/голубой акценты на тёмном
  фоне ~5.8–6.6:1, тёмный текст на оранжевой кнопке/баннере ~6.2:1 — везде выше порога AA
  (4.5:1 для обычного текста, 3:1 для крупного).

## Допущения (проверить с клиентом)

- Часы работы указаны как ежедневные 08:00–23:00 — в исходных данных не было разбивки
  по дням недели/выходным, использовано единое расписание.
- Ссылка на отзывы ведёт на **общий поиск 2ГИС** по названию
  (`https://2gis.ru/moscow/search/St.Riders%20Coffee`), а не на точную карточку/permalink
  заведения — реального ID организации в 2ГИС у меня не было, ссылку нужно заменить на
  прямую после проверки.
- VK-профиль упомянут только текстом («2ГИС и VK») без гиперссылки — точный адрес/handle
  паблика не был предоставлен, придумывать его не стал.
- Фраза «в пешей доступности от метро «Таганская»» — географическое предположение по
  названию улицы, точное время в минутах не указывалось и не проверялось.
- Название/состав фирменных напитков («Питстоп-латте», «Нитро-тоник», «Ред-флаг раф»,
  «Гараж-мокко») — креативные плейсхолдеры под стиль бренда, реальной рецептуры и точных
  названий в исходных данных не было; под каждым блоком есть пометка «уточняйте у бариста».
  Цены нигде не указаны, как и требовалось.
- Способы оплаты (карта / наличные / СБП, без предоплаты) описаны как типовые для
  подобных заведений — конкретный перечень платёжных систем клиент не присылал, при
  необходимости скорректировать.
- Процедура выдачи карты «Карта Райдера» («оформляется у бариста при заказе») —
  предположение для связности текста, реальный процесс не описывался.
- OG-превью не подключает `og:image` (нет реального фото заведения) — при желании можно
  сгенерировать брендированную SVG-заглушку, но data URI для `og:image` ненадёжно
  разворачивается большинством краулеров соцсетей, поэтому оставил без изображения.

## Требует решения от клиента

- Реальные фотографии интерьера/напитков для замены CSS/SVG-графики в галерее (сейчас
  осознанно без стоковых фото, как просили).
- Точный ID/ссылка карточки на 2ГИС и реальный адрес паблика VK.
- Точные цены и финальные названия позиций меню.
- Уточнить график работы по дням, если отличается от ежедневного 08:00–23:00.
- Юридические реквизиты для футера (ИНН/ОГРНИП), если требуются по закону о рекламе —
  сейчас указано только «ИП Васильев Андрей Дмитриевич» из вводных.

## Не могу проверить

- **Lighthouse/автоматический аудит производительности и SEO** — Node.js и npm не
  установлены в системе по условию задачи, поэтому CLI-инструменты (lighthouse,
  pa11y и т.п.) недоступны. Качество и доступность проверялись вручную: чтение DOM/текста
  страницы, проверка консоли на ошибки JS (ошибок нет), ручной расчёт контраста по
  WCAG-формуле относительной яркости (см. раздел «Сделано»).
- **Скриншоты финального рендера** — в текущей песочнице панель браузера не выводит кадры
  (скриншот таймаутится с ошибкой «Browser pane is not displayed»), поэтому визуальная
  проверка вёрстки на 360px и десктопе сделана через чтение accessibility-дерева и текста
  страницы, а не глазами. Рекомендуется открыть `index.html` в обычном браузере и сверить
  вёрстку вживую перед сдачей клиенту.
